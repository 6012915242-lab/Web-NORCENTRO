INSTALACIÓN DEL BACKEND DE LARAVEL

Requisitos: PHP 8.3 o superior con PDO MySQL, mbstring, openssl y zip,
Composer, Apache y MariaDB/MySQL. La página actual y el ORM artesanal
permanecen en la carpeta principal del proyecto.

1. Importar las bases y ejecutar las migraciones SQL de Norcentro siguiendo
   los archivos de la carpeta sql. No ejecutar artisan migrate sobre una base
   con datos existentes: las migraciones incluidas son las del ejemplo Laravel.
2. En esta carpeta ejecutar composer install.
3. Copiar .env.example a una carpeta privada fuera de htdocs, llamada
   norcentro_config, y renombrar la copia a .env. En XAMPP instalado en
   C:\xampp83, la ruta predeterminada es C:\xampp83\norcentro_config\.env.
   Para otra ruta, definir la variable de entorno NORCENTRO_LARAVEL_ENV_DIR
   con la carpeta privada antes de iniciar Apache y la consola.
4. Configurar en ese archivo DB_HOST, DB_PORT, DB_DATABASE, DB_USERNAME y
   DB_PASSWORD. Cada integrante debe usar sus propios datos locales.
5. Ejecutar php artisan key:generate para crear la clave de la aplicación.
6. Ejecutar php artisan test para comprobar las pruebas automatizadas.

Laravel se encuentra en backend-laravel/public. Su API de clientes requiere
una sesión Laravel y los permisos correspondientes. La página principal
existente sigue en public y aún no ha sido migrada por completo a Laravel.
Nunca compartir el archivo .env, la carpeta vendor ni credenciales privadas.
